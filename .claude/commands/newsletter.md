# Compile Weekly Newsletter

Compile the week's best content into a Substack newsletter draft.

## Usage

```
/newsletter [week-of-date]
```

If no date provided, uses the current week.

## Instructions

1. Scan atoms/ for all content created this week
2. Read the source pillars for context
3. Read voice/tone-guide.md for newsletter tone (personal, intimate)

4. Compile newsletter with this structure:

```markdown
# [Weekly Title - Something Catchy]

Hey friends,

[1-2 paragraph personal intro - what happened this week, what I'm thinking about]

---

## This Week's Best

### [Pillar 1 Title]

[200-300 word summary with key insight]
[Link to full post on thoughts.anipotts.com]

### [Pillar 2 Title] (if applicable)

[200-300 word summary]
[Link]

---

## Quick Hits

- [Interesting thing I found this week]
- [Tool/resource worth checking out]
- [Hot take or observation]

---

## What I'm Working On

[Behind-the-scenes update - projects, learning, etc.]

---

## One Thing to Try This Week

[Actionable tip the reader can immediately use]

---

Until next time,
Ani

P.S. [Something personal, funny, or teaser for next week]
```

5. Save to: `atoms/substack/YYYY-MM-DD-weekly.substack.md`

6. Show preview and word count

## Tone

- Like writing to a friend who subscribed because they like your stuff
- Personal updates mixed with value
- Not a content dump - curated and contextualized
