# Find Engagement Opportunities

Search for accounts and content to engage with authentically.

## Usage
```
/engage [platform]
```

Platform options: twitter, linkedin, instagram, tiktok, reddit, all

## Instructions

1. Read engagement/accounts-to-engage.md for existing targets
2. Search for new opportunities based on Ani's niche:
   - Claude Code / AI tools
   - Agentic coding (Cursor, Copilot, Windsurf)
   - Productivity / life optimization
   - Build in public
   - Indie hackers / solo founders

3. For each platform, identify:

### Accounts to Follow/Engage
- Handle
- Follower count (prefer 1k-50k - reachable, engaged)
- What they post about
- Engagement style (threads, videos, hot takes?)

### Content to Comment On
- Specific post/thread URL
- What it's about
- Suggested genuine comment angle
- Why this engagement matters

### Communities to Participate In
- Subreddits
- Discord servers
- LinkedIn groups

4. Output to engagement/accounts-to-engage.md in this format:

```markdown
## Updated: {{DATE}}

### Twitter/X
| Handle | Followers | Niche | Recent Post to Engage | Comment Angle |
|--------|-----------|-------|----------------------|---------------|
| @example | 15k | Claude Code | [link] | Agree and add your experience |

### Instagram
...

### Reddit
| Subreddit | Members | Activity | Type of Posts That Do Well |
|-----------|---------|----------|---------------------------|
| r/ClaudeAI | 50k | High | Tips, comparisons, workflows |
```

## Engagement Philosophy

- **Genuine > Strategic**: Don't comment just to be seen. Add real value.
- **Consistency > Bursts**: 5-10 quality comments daily > 50 in one day
- **Give before you take**: Help others before promoting yourself
- **Be memorable**: Hot takes, unique perspectives, genuine reactions
